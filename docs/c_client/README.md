# C API Reference

> **Status: NORMATIVE** · Scope: go-objstore · Last verified: 2026-11-12
> Conflicts with this document are defects. Fix them here first.

Complete reference for using go-objstore from C applications.

## Overview

The go-objstore C API provides access to all storage backends through a simple C interface. The library is compiled as a shared object (.so) file that can be linked with C applications.

## Building the Library

From the project root:

```bash
make lib
```

The target runs `go build -buildmode=c-shared -o bin/libobjstore.so ./cmd/objstorelib`
with the build tags it prints on its second line (`Build tags: ...`), then moves
the header that cgo generates next to the library into the C example directory.
It produces:
- `bin/libobjstore.so` - the shared library
- `examples/c_client/libobjstore.h` - the C header, generated by `make lib` on
  every build. It is not committed (`examples/c_client/.gitignore` ignores it);
  run `make lib` before compiling against it.

`examples/c_client/Makefile` relies on both: its sources include
`"libobjstore.h"` from their own directory, it links `../../bin/libobjstore.so`,
and its `run` and `example` targets set `LD_LIBRARY_PATH=../../bin`. Its
`check-lib` target stops with an error when either file is missing.

```bash
make lib
cd examples/c_client
make            # builds test_objstore and simple_example
make example    # runs simple_example
make run        # runs the C API test suite
```

## API Functions

The prototypes below are those of the generated `libobjstore.h`. Every
function that returns `int` reports failure as `-1` and records a message for
`ObjstoreGetLastError()`; every call that succeeds clears that message.

### Version Information

#### ObjstoreVersion

```c
char* ObjstoreVersion(void);
```

Returns the library version string (currently the fixed text `go-objstore v0.1.0`), newly allocated on each call. **Caller must free the returned string** using `ObjstoreFreeString()`.

**Example:**
```c
char *version = ObjstoreVersion();
printf("Version: %s\n", version);
ObjstoreFreeString(version);
```

---

### Storage Management

#### ObjstoreNewStorage

```c
int ObjstoreNewStorage(char* backendType, char** settingsKeys, char** settingsValues, int settingsCount);
```

Creates a storage backend and returns a handle to it.

**Parameters:**
- `backendType` - a registered storage backend ID (see
  [Backend Configuration](#backend-configuration)): `local` and `memory`
  always; `s3`, `gcs` and `azure` only when the library was built with their
  tags. `glacier` and `azurearchive` are archive-only and are refused here.
- `settingsKeys` - array of `settingsCount` configuration key strings
- `settingsValues` - array of `settingsCount` configuration value strings
- `settingsCount` - number of key-value pairs; negative is an error

The library copies the strings during the call and keeps no pointer to them.

**Returns:**
- a positive handle on success (handles start at 1 and are never reused)
- -1 on error (check `ObjstoreGetLastError()`), including an unknown or
  archive-only backend ID

**Example:**
```c
char *keys[] = {"path"};
char *values[] = {"/tmp/storage"};
int handle = ObjstoreNewStorage("local", keys, values, 1);
if (handle < 0) {
    char *err = ObjstoreGetLastError();
    fprintf(stderr, "Error: %s\n", err);
    ObjstoreFreeString(err);
}
```

A key such as `accessKey`, `secretKey`, `accountKey`, `sasToken` or
`sessionToken` in `keys` is refused. Use `ObjstoreNewStorageWithCredentials`
to pass a credential.

#### ObjstoreNewStorageWithCredentials

```c
int ObjstoreNewStorageWithCredentials(char* backendType, char** settingsKeys, char** settingsValues,
                                      int settingsCount,
                                      char* key, int keyLen,
                                      char* secret, int secretLen);
```

Like `ObjstoreNewStorage`, and additionally takes a credential as two byte
buffers with explicit lengths (not NUL-terminated strings). The library copies
each buffer into a protected-memory handle at the call boundary, builds the
backend from the handle, destroys the handle and zeroizes its own copy before
it returns, and keeps no copy of the credential afterwards.

**Parameters:**
- `backendType`, `settingsKeys`, `settingsValues`, `settingsCount` - as for `ObjstoreNewStorage`
- `key`, `keyLen` - access key (S3). `NULL` with `0` passes none
- `secret`, `secretLen` - secret key (S3) or account key (Azure). `NULL` with `0` passes none

Passing neither buffer selects the SDK default credential chain. A `NULL`
buffer with a non-zero length, or a negative length, is an error.

**Caller's duty:** the library cannot reach your buffers. Wipe them as soon as
the call returns, with `explicit_bzero` (POSIX) or `SecureZeroMemory`
(Windows), never `memset`, which the compiler may remove. The library receives
the bytes as given, so any copy you made earlier is yours to wipe.

**Example:**
```c
char key[] = "AKIA...";
char secret[] = "...";
char *keys[] = {"region", "bucket"};
char *values[] = {"us-east-1", "my-bucket"};

int h = ObjstoreNewStorageWithCredentials("s3", keys, values, 2,
                                          key, (int)strlen(key),
                                          secret, (int)strlen(secret));
explicit_bzero(key, sizeof key);
explicit_bzero(secret, sizeof secret);
if (h < 0) {
    char *err = ObjstoreGetLastError();
    fprintf(stderr, "Error: %s\n", err);
    ObjstoreFreeString(err);
}
```

#### ObjstoreClose

```c
void ObjstoreClose(int handle);
```

Removes the handle from the library's handle map. Later calls with it fail
with `invalid storage handle`. The library does not call a close method on the
backend; it drops its reference to it. Closing an unknown handle is not an
error. Clears the last error.

**Parameters:**
- `handle` - Storage handle to close

**Example:**
```c
ObjstoreClose(handle);
```

### Data Operations

#### ObjstorePut

```c
int ObjstorePut(int handle, char* key, char* data, int dataLen);
```

Stores data in the storage backend.

**Parameters:**
- `handle` - Storage handle
- `key` - Object key/path
- `data` - Data to store
- `dataLen` - Length of data in bytes; negative is an error

The library copies `dataLen` bytes from `data` before it writes, and keeps no
pointer to them.

**Returns:**
- 0 on success
- -1 on error

**Example:**
```c
const char *data = "Hello, World!";
int result = ObjstorePut(handle, "greeting.txt", (char*)data, strlen(data));
if (result != 0) {
    char *err = ObjstoreGetLastError();
    fprintf(stderr, "Put failed: %s\n", err);
    ObjstoreFreeString(err);
}
```

#### ObjstoreGet

```c
int ObjstoreGet(int handle, char* key, char* buffer, int bufferSize);
```

Retrieves data from storage into a buffer.

**Parameters:**
- `handle` - Storage handle
- `key` - Object key/path
- `buffer` - Buffer to receive data
- `bufferSize` - Size of buffer in bytes; negative is an error

**Returns:**
- Number of bytes copied into `buffer` on success (0 for an empty object)
- -1 on error

**Notes:**
- The library reads the whole object, then copies it into `buffer`. If the
  object is larger than `bufferSize`, nothing is copied, -1 is returned and the
  error reads `buffer too small: need N bytes, have M`.
- The buffer is **not** NUL-terminated. To use it as a string, pass one byte
  less than its size and terminate it yourself, as below.

**Example:**
```c
char buffer[1024];
int bytes = ObjstoreGet(handle, "greeting.txt", buffer, sizeof(buffer) - 1);
if (bytes >= 0) {
    buffer[bytes] = '\0';
}
if (bytes < 0) {
    char *err = ObjstoreGetLastError();
    fprintf(stderr, "Get failed: %s\n", err);
    ObjstoreFreeString(err);
} else {
    printf("Read %d bytes: %s\n", bytes, buffer);
}
```

#### ObjstoreDelete

```c
int ObjstoreDelete(int handle, char* key);
```

Deletes an object from storage.

**Parameters:**
- `handle` - Storage handle
- `key` - Object key/path

**Returns:**
- 0 on success
- -1 on error

**Example:**
```c
int result = ObjstoreDelete(handle, "old-file.txt");
if (result != 0) {
    char *err = ObjstoreGetLastError();
    fprintf(stderr, "Delete failed: %s\n", err);
    ObjstoreFreeString(err);
}
```

### Error Handling

#### ObjstoreGetLastError

```c
char* ObjstoreGetLastError(void);
```

Returns a copy of the last error message. The library keeps one last-error
string for the whole process, not one per thread or per handle: every call
that fails sets it and every call that succeeds clears it, whichever thread
made the call.

**Returns:**
- Error message string, newly allocated
- NULL if the last call succeeded
- **Caller must free the returned string** using `ObjstoreFreeString()`

**Example:**
```c
if (result < 0) {
    char *err = ObjstoreGetLastError();
    if (err != NULL) {
        fprintf(stderr, "Error: %s\n", err);
        ObjstoreFreeString(err);
    }
}
```

---

### Memory Management

#### ObjstoreFreeString

```c
void ObjstoreFreeString(char* str);
```

Frees a string allocated by the library (it calls C `free`). Passing `NULL`
is safe; passing any other pointer the library did not return, or one already
freed, is undefined.

**Parameters:**
- `str` - String to free (from `ObjstoreVersion()` or `ObjstoreGetLastError()`)

**Example:**
```c
char *version = ObjstoreVersion();
printf("%s\n", version);
ObjstoreFreeString(version);
```

## Backend Configuration

`ObjstoreNewStorage` and `ObjstoreNewStorageWithCredentials` accept the
storage backend IDs registered in the library at build time:

| ID | Registered when |
|----|-----------------|
| `local` | always |
| `memory` | always |
| `s3` | built with the `awss3` tag |
| `gcs` | built with the `gcpstorage` tag |
| `azure` | built with the `azureblob` tag |

`make lib` prints the tags it builds with; by default they are
`local awss3 gcpstorage azureblob glacier azurearchive`, so all five IDs are
registered. `glacier` and `azurearchive` are archive backends, not storage
backends: passing either ID returns -1. An unregistered ID returns -1 as well.

A credential never travels in the settings arrays. A key such as `accessKey`,
`secretKey`, `accountKey`, `sasToken` or `sessionToken` in `settingsKeys` is
refused; pass the credential to `ObjstoreNewStorageWithCredentials`, which moves
it into a protected-memory handle.

### Local Storage

```c
char *keys[] = {"path"};
char *values[] = {"/var/data"};
int h = ObjstoreNewStorage("local", keys, values, 1);
```

**Configuration:**
- `path` - Directory path for local storage

### Memory

```c
int h = ObjstoreNewStorage("memory", NULL, NULL, 0);
```

An in-process store with no settings; its contents are lost when the process exits.

### Amazon S3

```c
char *keys[] = {"region", "bucket"};
char *values[] = {"us-east-1", "my-bucket"};

/* With the SDK default credential chain: */
int h = ObjstoreNewStorage("s3", keys, values, 2);

/* With an explicit credential, never in keys/values: */
int h2 = ObjstoreNewStorageWithCredentials("s3", keys, values, 2,
                                           key, key_len, secret, secret_len);
/* then explicit_bzero() your key and secret buffers */
```

**Configuration:**
- `region` - AWS region (e.g., "us-east-1")
- `bucket` - S3 bucket name

**Credentials:**
Pass the access key and secret key to `ObjstoreNewStorageWithCredentials` (see
above). When none is passed, the AWS SDK credential chain applies:
1. Environment variables (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`)
2. AWS credentials file (`~/.aws/credentials`)
3. IAM instance role

### Google Cloud Storage

```c
char *keys[] = {"bucket"};
char *values[] = {"my-gcs-bucket"};
int h = ObjstoreNewStorage("gcs", keys, values, 1);
```

**Configuration:**
- `bucket` - GCS bucket name

**Credentials:**
Uses Google Application Default Credentials:
1. `GOOGLE_APPLICATION_CREDENTIALS` environment variable
2. gcloud CLI credentials
3. Compute Engine service account

### Azure Blob Storage

```c
char *keys[] = {"accountName", "containerName"};
char *values[] = {"myaccount", "mycontainer"};
int h = ObjstoreNewStorageWithCredentials("azure", keys, values, 2,
                                          NULL, 0,
                                          account_key, account_key_len);
/* then explicit_bzero() your account key buffer */
```

**Configuration:**
- `accountName` - Azure storage account name
- `containerName` - Blob container name

**Credentials:** a credential never travels in the settings arrays. A key such as
`accountKey`, `accessKey` or `secretKey` is rejected with an error. Pass the
account key as the `secret` of `ObjstoreNewStorageWithCredentials` (see above);
Azure reads only the secret and ignores `key`.

## Complete Example

```c
#include <stdio.h>
#include <string.h>
#include "libobjstore.h"

int main(void) {
    // Create storage
    char *keys[] = {"path"};
    char *values[] = {"/tmp/data"};
    int h = ObjstoreNewStorage("local", keys, values, 1);
    if (h < 0) {
        char *err = ObjstoreGetLastError();
        fprintf(stderr, "Error: %s\n", err);
        ObjstoreFreeString(err);
        return 1;
    }

    // Store data
    const char *data = "Important data";
    if (ObjstorePut(h, "file.txt", (char*)data, strlen(data)) != 0) {
        char *err = ObjstoreGetLastError();
        fprintf(stderr, "Put error: %s\n", err);
        ObjstoreFreeString(err);
        ObjstoreClose(h);
        return 1;
    }

    // Retrieve data
    char buffer[256];
    int bytes = ObjstoreGet(h, "file.txt", buffer, sizeof(buffer) - 1);
    if (bytes < 0) {
        char *err = ObjstoreGetLastError();
        fprintf(stderr, "Get error: %s\n", err);
        ObjstoreFreeString(err);
        ObjstoreClose(h);
        return 1;
    }
    buffer[bytes] = '\0'; /* ObjstoreGet does not NUL-terminate */
    printf("Retrieved: %s (%d bytes)\n", buffer, bytes);

    // Cleanup
    ObjstoreDelete(h, "file.txt");
    ObjstoreClose(h);
    return 0;
}
```

## Memory Rules

**You allocate and own:**
- The buffer passed to `ObjstoreGet()`
- The data buffer passed to `ObjstorePut()`
- The backend ID, object keys and configuration key/value arrays
- The credential buffers passed to `ObjstoreNewStorageWithCredentials()`
  (wipe them after the call)

The library copies what it needs from these during the call and keeps no
pointer to any of them after it returns.

**You must free, with `ObjstoreFreeString()`:**
- Every string returned by `ObjstoreVersion()`
- Every non-NULL string returned by `ObjstoreGetLastError()`

These are the only two functions that return memory to the caller. Each call
returns a new copy, allocated with C `malloc`.

**The library owns:**
- The backend behind each handle. `ObjstoreClose()` removes the handle from
  the library's map and drops the library's reference; it does not call a
  close method on the backend.

## Error Handling Best Practices

1. **Always check return values**
   ```c
   if (result < 0) {
       // Handle error
   }
   ```

2. **Get error details**
   ```c
   char *err = ObjstoreGetLastError();
   if (err != NULL) {
       fprintf(stderr, "%s\n", err);
       ObjstoreFreeString(err);
   }
   ```

3. **Clean up on errors**
   ```c
   if (handle >= 0) {
       ObjstoreClose(handle);
   }
   ```

## Thread Safety

What the library does:
- The handle map (handle number to backend) is guarded by one mutex. Creating,
  looking up and closing handles from several threads is safe.
- The last-error string is a single process-wide value guarded by its own
  mutex. Reading it is safe, but a call on another thread can set or clear it
  between your failing call and your `ObjstoreGetLastError()`, so the message
  may belong to another call.
- `ObjstorePut`, `ObjstoreGet` and `ObjstoreDelete` take no per-handle lock:
  concurrent calls on one handle reach the backend concurrently.

What the library does not promise: that a given backend is safe for concurrent
use on one handle, or that an error message belongs to your thread. If you need
either, serialize the calls (for example, a mutex around each call and its
`ObjstoreGetLastError()`), or use a separate handle per thread.

## Compilation

Run `make lib` first: it produces `bin/libobjstore.so` and generates
`examples/c_client/libobjstore.h`. Include the header as `"libobjstore.h"`,
put its directory on the include path, and link the library by name:

### Linux

```bash
GO_OBJSTORE=/path/to/go-objstore
gcc -I"$GO_OBJSTORE/examples/c_client" -o myapp myapp.c \
    -L"$GO_OBJSTORE/bin" -lobjstore -lpthread -ldl
```

`-lobjstore` finds `libobjstore.so` in the `-L` directory. Passing the file
itself (`"$GO_OBJSTORE/bin/libobjstore.so"`) instead of `-L... -lobjstore`
works too; `examples/c_client/Makefile` does that.

### Running

The library is not installed in a system path, so tell the loader where it is:

```bash
export LD_LIBRARY_PATH=/path/to/go-objstore/bin:$LD_LIBRARY_PATH
./myapp
```
